# Development Setup

## Requirements

| Requirement | Notes |
|--------------|-------|
| **Windows 10/11** | Target platform |
| **Node.js** | For the frontend build |
| **Rust toolchain** | For the Tauri backend |
| **WebView2 Runtime** | Ships with Windows 10/11 by default |

## Clone and Install

```powershell
git clone <this-repo-url>
cd TablePro
npm ci
```

## Run in Development

```powershell
npm run dev:tauri
```

This starts the Vite dev server and launches the Tauri app pointed at it.

## Run Tests

```powershell
npx vitest run
```

Rust tests, from `src-tauri/`:

```powershell
cargo test --workspace
```

## Lint

```powershell
npx eslint .
cargo clippy --workspace --all-targets -- -D warnings
```

## Building

See [Building](/development/building) for debug builds, release packaging (MSI/NSIS), and CI.

## Troubleshooting

**Build fails after pulling changes**: run `npm ci` again to pick up dependency changes, and `cargo clean` in `src-tauri/` if Rust build artifacts seem stale.

**Non-Windows dev machines (e.g. WSL)**: all build/test/lint/package commands must run through Windows PowerShell against the Windows Rust/Node toolchains — running them against a Linux toolchain produces results that don't reflect the real (Windows-only) product.
