# Building TablePro

Windows-only. Every build, test, lint, and package command runs through PowerShell. Run from the repository root unless noted.

## Install Dependencies

```powershell
npm ci
```

## Development

```powershell
npm run dev          # frontend dev server
npm run dev:tauri     # full Tauri dev app
```

## Debug Build

```powershell
npm run build:debug
```

## Quality Gates

Frontend, from the repository root:

```powershell
npx vitest run
npx eslint .
npm run build
```

Rust, from `src-tauri/`:

```powershell
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
```

## Release Packaging

```powershell
npm run build:portable
npm run build:installer
npm run build:release
```

Or directly:

```powershell
npx tauri build
```

This produces both installer formats:

```
src-tauri\target\release\bundle\msi\TablePro_<version>_x64_en-US.msi
src-tauri\target\release\bundle\nsis\TablePro_<version>_x64-setup.exe
```

<Warning>
`npx tauri build` can exit with a non-zero code on a transient PowerShell stderr-as-terminating-error during toolchain fetch, even when packaging actually succeeds — and conversely a clean exit code isn't proof the artifacts are real. Always verify by checking the bundle files exist with a sane size after wiping `src-tauri\target\release\bundle` and rebuilding.
</Warning>

## Version Bump

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bump-version.ps1 -Version X.Y.Z
```

Updates `package.json`, `src-tauri/tauri.conf.json`, and `src-tauri/Cargo.toml` (main app crate only — driver crates stay independently versioned).

## Code Signing

CI imports a code-signing certificate from a GitHub secret (`WINDOWS_SIGN_CERT_BASE64` / `WINDOWS_SIGN_CERT_PASSWORD`) as a `.pfx` and signs the build via `Import-PfxCertificate`. Local builds are unsigned by default.

## Troubleshooting

**PowerShell command chaining**: run one native command per `powershell.exe -Command` invocation — `-Command "a; b"` executes `b` even if `a` failed, and only reports `b`'s exit code.

**Line endings**: pipe PowerShell output through `tr -d '\r'` before parsing in a non-Windows shell.

**Never run cargo/npm against a non-Windows toolchain** for this project — it is Windows-only and the results won't reflect the real build.

## CI

The only CI pipeline is [`.github/workflows/windows-build.yml`](https://github.com/miken90/TablePro/blob/main/.github/workflows/windows-build.yml), which runs `cargo clippy`, `cargo test`, `npx vitest run`, `npx eslint .`, `npm run build`, and `npx tauri build`.
