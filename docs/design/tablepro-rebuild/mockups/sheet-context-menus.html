Context menus

Anchored popovers — no scrim, Esc or outside click closes, focus returns to the trigger.

SCR-05

Sidebar Database Context Menu

Right-click a database node in SCR-04.

States: open / closed only. Both items refetch without reconnecting. Under M6 these two also appear as the tree header's refresh control, so this menu is a shortcut, no longer the only way in.

SCR-07

Tab Context Menu

Right-click a tab in SCR-06.

States: the first item is the only one that changes — a pinned tab reads Unpin Tab in the same slot. Closing a dirty tab routes through SCR-45 Confirm Discard rather than closing outright. None of these items is destructive in the 5.16 sense: closing a tab writes nothing.

SCR-10

Connection Card Context Menu

Right-click a connection card in SCR-08.

States: items are conditional on the handler being supplied, so a card can show fewer. Edit opens SCR-09, Export opens SCR-11, Copy import link writes to the clipboard and closes. Delete is red-label, not red-fill: it opens a confirmation and writes nothing itself, which is the 5.16 rule for .btn.danger-ghost. The filled red button is the one inside that dialog.
