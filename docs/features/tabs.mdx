# Query Tabs

Every tab is an independent workspace with its own SQL content, results, pagination, sorting, and filter state. Open as many as you need. They persist across app restarts.

## Tab Types

| Type | Icon | Purpose |
|------|------|---------|
| **Query Tab** | Document icon | Write and execute custom SQL |
| **Table Tab** | Table icon | Browse table data with pagination and filtering |
| **Structure Tab** | Boxes icon | A table's columns, indexes, foreign keys, and DDL (see [Table Structure](/features/table-structure)) |

**Query tabs** start with an empty editor. Type SQL and press `Ctrl+Enter` to execute.

**Table tabs** open when you click a table in the sidebar. They provide server-side pagination, inline editing with change tracking, and filter support. Closing a table tab that has unsaved row edits asks first; Discard drops that table's edits.

**Structure tabs** open from the sidebar's **View Structure** action (or a double-click on a table) and sit beside the other tabs.

<Tip>
Table tabs support inline cell editing and change tracking. Query tabs are always read-only — there is no inline editing in a query tab's result grid, regardless of what the query selects.
</Tip>

### Smart Tab Reuse

Clicking the same table switches to its existing tab. Clicking a different table opens a new tab — there is no setting to make it replace the current table tab.

### Preview Tabs

Single-clicking a table in the sidebar opens a permanent table tab directly; it is not a preview. To open a preview instead, hold `Ctrl` while clicking a table: this opens a query tab pre-filled with `SELECT * FROM <table> LIMIT 100;` and runs it immediately. `Ctrl`-clicking a different table reuses that same preview tab (replacing its content) rather than opening a new one.

Preview tabs render italicized and slightly dimmed in the tab bar — there is no "Preview" text in a window subtitle.

A preview tab becomes permanent when you:

- **Double-click** the tab itself in the tab bar
- **Edit** its SQL

Double-clicking a table *in the sidebar* opens that table's Structure tab; it does not affect preview tabs.

Preview tabs are saved across restarts like any other tab, but restore as permanent tabs — the preview flag itself is not persisted.

## Managing Tabs

### Creating Tabs

| Action | How |
|--------|-----|
| New query tab | `Ctrl+T` or click **+** in the tab bar |
| Jump to query tab | Click **Query Editor** in the result panel's toolbar (reuses the active or most recent query tab; opens a new one only if none exists) |
| New table tab | Click a table name in the sidebar |

### Closing Tabs

| Action | How |
|--------|-----|
| Close current tab | `Ctrl+W` |
| Close specific tab | Hover and click **x** |
| Close other tabs | Right-click > **Close Others** |

<Warning>
Closing a tab with unsaved changes discards those changes. TablePro warns you before closing if there are pending data modifications.
</Warning>

### Switching Tabs

- `Ctrl+Tab` for next tab
- `Ctrl+Shift+Tab` for previous tab

Each tab preserves its full state when you switch away: SQL content, cursor position, results, scroll position, selected rows, and sort/filter state. Pending changes are scoped to the table being edited, not the tab — see [Change Tracking Scope](#change-tracking-scope).

### Tab Order

Tabs cannot be dragged to reorder. Pinned tabs are always sorted to the front of the tab bar; unpinned tabs keep the order in which they were opened. The tab bar scrolls horizontally when tabs overflow.

### Pinning Tabs

Right-click a tab > **Pin Tab**. Pinned tabs:

- Have their hover-to-close (**x**) button hidden
- Are skipped by **Close Others**, **Close All**, and **Close to the Right**
- Persist across sessions

Pinning does not protect a tab from the context menu's own **Close** item or from `Ctrl+W` on the active tab — those close a pinned tab the same as any other.

Unpin via right-click > **Unpin Tab**.

## Change Tracking Scope

Pending row edits are keyed by table (connection + schema + table name), not by tab. Two table tabs open on the *same* table share one set of staged edits and one undo/redo stack — editing a row in one shows the same staged edit in the other. Table tabs on *different* tables never interfere with each other. Switching tabs restores whichever table's staged edits (if any) belong to the tab you switch to.

## Per-Tab Data Caching

When switching between multiple active table tabs, TablePro keeps the query results, pagination page, sorting state, and column metadata cached in memory. This prevents automatic re-fetching of table data from the database server on every tab switch, saving network bandwidth and database resources. Manual refreshes (pressing **F5** or clicking the refresh button) will bypass the cache and fetch fresh data from the server.

## Tab Persistence

### What Is Persisted

| Saved | Not Saved |
|-------|-----------|
| Tab ID and title | Query results (re-queried on reopen) |
| SQL content | Pending data changes |
| Tab type and table name | Selected rows, sort/filter state |
| Pin state | Preview state (a preview tab restores as a permanent tab) |

Tab state auto-saves 800ms after any change. On reconnect, TablePro restores your tabs and re-executes table queries.

## Pagination

### Table Tabs (Server-Side)

Table tabs use SQL `LIMIT` and `OFFSET`. Only the current page loads from the database. Page navigation triggers a new query. Configure page size in **Settings** > **General**.

<Tip>
Server-side pagination is memory efficient. Only the visible page is kept in memory, even for tables with millions of rows.
</Tip>

### Query Tabs (Client-Side)

Query tabs execute the full query and receive all results. For large result sets, TablePro paginates client-side without re-querying. Sorting is done locally on cached results.

Configure page size in **Settings** > **General**: 25, 50, 100, 500, or 1000 rows.

## Tab Context Menu

Right-click any tab:

| Action | Description |
|--------|-------------|
| **Pin Tab** / **Unpin Tab** | Toggle pin state |
| **Close** | Close this tab |
| **Close Others** | Close all except this one (skips pinned tabs) |
| **Close All** | Close every tab (skips pinned tabs) |
| **Close to the Right** | Close every tab after this one (skips pinned tabs) |

There is no **Duplicate Tab** action.
