# Table Operations

Right-click a table or view in the sidebar for table-level operations.

## Table Context Menu

For tables (not views), right-click offers:

| Action | Effect |
|--------|--------|
| **Truncate Table** | Removes all rows, keeps table structure (SQLite has no `TRUNCATE`, so it runs `DELETE FROM`, which SQLite optimises into the same thing) |
| **Delete All Records** | Deletes all rows (DML, not DDL) |
| **Drop Table** | Permanently deletes the table and its data |

For views, only **Drop View** is offered (no truncate / delete-all-records, since a view has no rows of its own), and it emits `DROP VIEW` rather than `DROP TABLE`.

All three ask you to type the table's name before the confirm button is enabled; pressing `Enter` does nothing until the typed name matches.

The statement itself is generated by the backend, so identifiers are quoted for the connected engine (backticks on MySQL/MariaDB, brackets on SQL Server, double quotes elsewhere) and quote characters inside a name are escaped.

<Warning>
Dropping a table is irreversible.
</Warning>

<Note>
These operations run through the same execution path as the SQL editor, so [Safe Mode](/features/safe-mode) applies: at **Read-Only** they are blocked, and at the confirming levels the Safe Mode dialog appears after the table operation dialog.
</Note>

## Database Switcher

Click the database name in the toolbar to browse and switch databases on the current connection.
