# Keyboard Shortcuts

TablePro is keyboard-driven. Most actions have shortcuts, and the shortcuts below (except tab-switching) are rebindable in **Settings** > **Shortcuts**.

## Quick Reference

| Action | Shortcut |
|--------|----------|
| Run query | `Ctrl+Enter` |
| Quick Switcher | `Ctrl+K` |
| Toggle History | `Ctrl+H` |
| Settings | `Ctrl+,` |
| Save changes | `Ctrl+S` |
| Command Palette | `Ctrl+Shift+P` |

## Query

| Action | Shortcut |
|--------|----------|
| Run query | `Ctrl+Enter` |
| Cancel query | `Escape` |
| Explain query | `Ctrl+Shift+X` |
| Format SQL | `Ctrl+Shift+F` |
| Toggle comment | `Ctrl+/` |

## Edit

| Action | Shortcut |
|--------|----------|
| New tab | `Ctrl+T` |
| Close tab | `Ctrl+W` |
| Next tab | `Ctrl+Tab` |
| Previous tab | `Ctrl+Shift+Tab` |
| Save changes | `Ctrl+S` |
| Insert row | `Ctrl+I` |
| Import SQL | `Ctrl+Shift+M` |

## Navigation

| Action | Shortcut |
|--------|----------|
| Quick Switcher | `Ctrl+K` |
| Toggle sidebar | `Ctrl+Shift+E` |
| Toggle AI Chat | `Ctrl+Shift+L` |
| Toggle Inspector | `Ctrl+Shift+I` |
| Toggle History | `Ctrl+H` |
| Command Palette | `Ctrl+Shift+P` |

## Settings

| Action | Shortcut |
|--------|----------|
| Settings | `Ctrl+,` |
| Refresh schema | `F5` |
| Keyboard Shortcuts help | `F1` |

## Data Grid

Standard grid navigation applies: arrow keys move between cells, `Tab`/`Shift+Tab` moves to the next/previous cell, `Enter` or `F2` edits a cell, `Escape` cancels an edit, and `Delete`/`Backspace` removes selected rows. Ctrl+Click extends row selection non-contiguously; Shift+Click selects a range.

## Vim Mode

When Vim mode is enabled (**Settings** > **Editor** > **Vim mode**), the SQL editor uses modal Vim keybindings. Vim mode only applies inside the SQL editor — it does not affect the data grid or other panels, and the shortcuts above still work.

## Quick Switcher

The Quick Switcher (`Ctrl+K`) searches and jumps to tables, views, databases, schemas, and recent queries with fuzzy matching. Results are grouped by type and ranked by match quality; the top match is pre-selected and updates as you type.

## Customizing Shortcuts

Most shortcuts above are rebindable in **Settings** > **Shortcuts**:

1. Open **Settings** (`Ctrl+,`) and select the **Shortcuts** tab
2. Click the shortcut next to the action
3. Press the new key combination
4. Save (or **Save Anyway** if it conflicts with another shortcut)
5. Click **Reset All** to restore every shortcut to its default binding

<Note>
Tab-switching shortcuts (`Ctrl+Tab` / `Ctrl+Shift+Tab`) are not in the rebindable command list.
</Note>
