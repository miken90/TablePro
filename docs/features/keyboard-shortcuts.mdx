# Keyboard Shortcuts

TablePro is keyboard-driven. Every shortcut below is rebindable in **Settings** > **Shortcuts**.

Shortcuts differ in **scope** — where you must be for them to fire:

| Scope | Meaning |
|-------|---------|
| Global | Works anywhere in the app |
| Editor | Only while the SQL editor has focus |
| Table browse | Only while browsing a table's data |

## Quick Reference

| Action | Shortcut | Scope |
|--------|----------|-------|
| Run query | `Ctrl+Enter` | Editor |
| Cancel running query | `Escape` | Global |
| Quick Switcher | `Ctrl+K` | Global |
| Toggle History | `Ctrl+H` | Global |
| Settings | `Ctrl+,` | Global |
| Command Palette | `Ctrl+Shift+P` | Global |

## Query

| Action | Shortcut | Scope |
|--------|----------|-------|
| Run query | `Ctrl+Enter` | Editor |
| Run all statements | `Ctrl+Shift+Enter` | Editor |
| Cancel running query | `Escape` | Global |
| Explain query | `Ctrl+Shift+X` | Editor |
| Format SQL | `Ctrl+Shift+F` | Editor |
| Toggle comment | `Ctrl+/` | Editor |
| Select next occurrence | `Ctrl+D` | Editor |

<Note>
`Escape` only cancels while a query is actually running. At any other time it
falls through to whatever else is on screen, so it still closes dialogs and
popovers as usual.
</Note>

| New tab | `Ctrl+T` | Global |
| Close tab | `Ctrl+W` | Global |

## Data Grid

Standard grid navigation applies: arrow keys move between cells, `Tab`/`Shift+Tab` moves to the next/previous cell, `Enter` edits a cell, `Escape` cancels an edit, and `Delete`/`Backspace` removes selected rows. Ctrl+Click extends row selection non-contiguously; Shift+Click selects a range.

## Vim Mode

When Vim mode is enabled (**Settings** > **Editor** > **Vim mode**), the SQL editor uses modal Vim keybindings. Vim mode only applies inside the SQL editor — it does not affect the data grid or other panels, and the shortcuts above still work.

## Quick Switcher and Command Palette

Quick Switcher and Command Palette are two modes of the same overlay. `Ctrl+K` opens it searching tables, views, databases, schemas, and recent queries with fuzzy matching — results are grouped by type and ranked by match quality, and the top match is pre-selected and updates as you type. `Ctrl+Shift+P` opens the same overlay in command mode, shown as a removable `>` chip in the input; typing `>` while searching objects switches to command mode the same way, and Backspace on an empty input drops the chip back to object search.

## Customizing Shortcuts

All shortcuts above are rebindable in **Settings** > **Shortcuts**:

1. Open **Settings** (`Ctrl+,`) and select the **Shortcuts** tab
2. Click the shortcut next to the action
3. Press the new key combination
4. Save (or **Save Anyway** if it conflicts with another shortcut)
5. Click **Reset All** to restore every shortcut to its default binding

<Note>
Rebinding affects every way a command can be triggered — the keyboard shortcut
and the entry shown in the Command Palette stay in sync.
</Note>
