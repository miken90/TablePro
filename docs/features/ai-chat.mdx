# AI Chat

Built-in AI chat panel for writing SQL. Supports OpenAI, OpenRouter, LM Studio, Ollama, and custom OpenAI-compatible endpoints.

## Opening the Panel

Press `Ctrl+Shift+L`, click the AI toolbar button, or run **Toggle AI Chat** from the Command Palette (`Ctrl+Shift+P`). AI Chat is one of three tabs (with Inspector and History) in the resizable right dock; opening it switches the dock to the AI tab.

## Chatting with AI

Type a question and press Enter (`Shift+Enter` for a newline). When a connection is active, the AI receives your database type and schema (table/column names, primary keys, foreign keys) as context. Responses render as markdown with fenced code blocks in plain monospace text (no syntax highlighting). Each code block has a **Copy** button. Token counts appear below each response when the provider returns usage data.

Conversations auto-save and auto-title from your first message. Browse history, start new conversations, or delete old ones from the panel.

Every response shows a **Retry** button that removes it and resends the last user message. Responses stream in real-time -- click **Stop** to cancel.

## Configuring AI Providers

Configure providers in **Settings** (`Ctrl+,`) > **AI**.

### Adding a Provider

Click **Add Provider**, choose a type, enter your API key, specify a model (or click **Fetch Models** to list available models), then **Test** to verify.

API keys are DPAPI-encrypted at rest, never in plain text.

### Feature Routing

Route each feature (Chat, Explain Query, Fix Error, Inline Suggestions) to a specific provider and model, or leave it unrouted to use the first enabled provider.

The **Max Schema Tables** slider (default 20) caps how many tables are included in the schema context sent to the AI. An **Inline Suggestions** toggle enables/disables AI-powered autocomplete in the editor.
