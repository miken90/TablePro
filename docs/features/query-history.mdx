# Query History

Every query you execute is automatically saved to a local SQLite database (with FTS5 full-text search). History persists across sessions.

## Accessing History

Open History:

- Press `Ctrl+H`
- Or click the **History** icon in the toolbar

History is one of three tabs (with Inspector and AI Chat) in the resizable
right dock. Opening it switches the dock to the History tab and shows it if
the dock was closed; pressing `Ctrl+H` again while History is the open tab
closes the dock.

## History Features

Each entry shows the query text, timestamp, execution time, row count, and success/error status.

## Searching History

Type in the search box to full-text search query text. Search is debounced; clearing the search field returns to the recent-queries list.

## Using History

- **Load a query**: click an entry to load it into the SQL editor (`onSelectQuery`)
- **Copy a query**: click the copy button on a row; a check icon confirms the copy
- **Delete an entry**: click the delete button on a row
- **Clear all history**: click **Clear All** in the panel header

<Warning>
Clearing history cannot be undone.
</Warning>

## History Storage

Query history lives in:

```
%APPDATA%\TablePro\history.sqlite3
```

<Note>
There is no retention/auto-cleanup setting (max entries, max age) — history grows until you clear it manually.
</Note>
