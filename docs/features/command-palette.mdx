# Command Palette

The Command Palette is a fast way to discover and execute any TablePro action without clicking menus. Open it with **Ctrl+Shift+P** and start typing.

## Overview

The Command Palette provides:

- **Fuzzy search** across all available actions
- **Keyboard-driven** discovery without mouse
- **Recent commands** at the top for quick access
- **Keyboard shortcuts** displayed next to commands
- **Organized by category** (Navigation, Query, Edit, View, Settings)

## Opening the Command Palette

Press **Ctrl+Shift+P** to open the command palette. On macOS, use **Cmd+Shift+P**.

The palette appears as a modal overlay with a search field focused and ready for typing.

## Searching Commands

Start typing to filter commands. The search is fuzzy, so:

- Type `run` to find "Run Query"
- Type `conn` to find "New Connection"
- Type `close` to find "Close Tab"

Results appear below the search field, grouped by category.

## Executing Commands

To execute a command:

1. Type to search and find the command
2. Press **Enter** or click the command name
3. The command executes immediately

Alternatively, use arrow keys to navigate and **Enter** to confirm.

## Navigation

| Action | Key |
|--------|-----|
| Move up | `Up Arrow` |
| Move down | `Down Arrow` |
| Execute | `Enter` |
| Dismiss | `Escape` |

## Command Categories

Commands are organized for easy discovery:

| Category | Examples |
|----------|----------|
| **Navigation** | Open Settings, Toggle Sidebar, Toggle History, Quick Switcher |
| **Query** | Run Query, Run All, Cancel Query, Format SQL |
| **Edit** | New Tab, Close Tab, Save Changes, Undo, Redo |
| **View** | Toggle Filter, Toggle Inspector, Focus Mode |
| **Settings** | Appearance, Keyboard Shortcuts, Connection Settings |

## Recent Commands

When you open the Command Palette without typing, recent commands appear at the top. This makes frequently-used actions instant to access.

The palette remembers up to 5 recent commands.

## Tips

<Tip>
Don't type the full command name. Fuzzy search works on partial matches. For example, type `fmt` to find "Format SQL".
</Tip>

<Tip>
The command palette shows keyboard shortcuts next to each command. This is a great way to learn shortcuts for your most-used actions.
</Tip>

<Tip>
If you can't remember the exact command, type a related word. For example, type `table` to find commands related to tables.
</Tip>

## Keyboard Shortcuts

The most common shortcuts are:

| Action | Shortcut |
|--------|----------|
| Command Palette | `Ctrl+Shift+P` (Windows) / `Cmd+Shift+P` (macOS) |
| Close Palette | `Escape` |
| Navigate | Arrow keys |
| Execute | `Enter` |
