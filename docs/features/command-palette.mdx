# Command Palette

The Command Palette is a fast way to discover and execute any TablePro command without clicking menus. Open it with **Ctrl+Shift+P** and start typing.

## Overview

The Command Palette provides:

- **Substring search** — matches if your text appears anywhere in the command's name or ID
- **Keyboard-driven** discovery without mouse
- **Recent commands** (last 5) at the top when the search field is empty
- **Keyboard shortcuts** displayed next to commands
- **Organized by category**: Query, Edit, Navigation, Settings

## Opening the Command Palette

Press **Ctrl+Shift+P** to open the command palette.

## Searching Commands

Start typing to filter commands by substring match against the command name:

- Type `run` to find "Run Query"
- Type `close` to find "Close Tab"
- Type `save` to find "Save Changes"

## Executing Commands

1. Type to search and find the command
2. Press **Enter** or click the command name
3. The command executes immediately

Alternatively, use arrow keys to navigate and **Enter** to confirm.

## Navigation

| Action | Key |
|--------|-----|
| Move up | `Up Arrow` |
| Move down | `Down Arrow` |
| Execute | `Enter` |
| Dismiss | `Escape` |

## Commands

The palette lists all 21 registered commands, grouped by category:

| Category | Commands |
|----------|----------|
| **Query** | Run Query, Cancel Query, Explain Query, Format SQL, Toggle Comment |
| **Edit** | New Tab, Close Tab, Next Tab, Previous Tab, Save Changes, Insert Row, Import SQL |
| **Navigation** | Quick Switcher, Toggle Sidebar, Toggle AI Chat, Toggle Inspector, Toggle History, Command Palette |
| **Settings** | Settings, Refresh Schema, Keyboard Shortcuts |

## Recent Commands

When you open the Command Palette without typing, the last 5 executed commands appear at the top.

## Tips

<Tip>
The command palette shows keyboard shortcuts next to each command — a good way to learn shortcuts for your most-used actions.
</Tip>

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Command Palette | `Ctrl+Shift+P` |
| Close Palette | `Escape` |
| Navigate | Arrow keys |
| Execute | `Enter` |
