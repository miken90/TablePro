---
title: Deep Links
description: Open a saved connection or import a new one via tablepro:// links
---

TablePro registers a `tablepro://` URL scheme. There is no support for opening standard database URLs (`mysql://`, `postgresql://`, etc.) directly from the OS — those schemes are only used inside the app for **Import from URL** on the connection form.

## URL Patterns

### Open a Connection

```
tablepro://open/connection/{connection-id}
```

Looks up a saved connection by its internal ID and connects (or focuses it if already connected). If the ID isn't found, the link is silently ignored (logged to console).

### Import a Connection

```
tablepro://import?name={n}&host={h}&port={p}&type={t}&username={u}
```

Creates a new saved connection directly — there is no review/confirmation dialog. If a connection with the same `name` already exists, the import is skipped (logged to console, no error shown to the user).

**Required:** at least `name` or `host`.
**Recognized parameters:** `name`, `host`, `port`, `type`, `username`. `type` defaults to `PostgreSQL` if omitted; `port` defaults to `5432`.

<Warning>
The imported connection is saved without a password — you'll need to add it manually after import.
</Warning>

## Triggering a Deep Link

Type or paste the URL into a browser's address bar, or run from PowerShell/cmd:

```powershell
start "" "tablepro://open/connection/abc-123"
```
