# Import & Export

Export query or table results to CSV, JSON, or SQL, and paste tabular data from the clipboard into the grid.

<Note>
An `.sql`/`.sql.gz` file importer (`import_preview` / `import_sql_file`) and an XLSX export writer exist in the backend, but neither is wired to any menu, button, or shortcut in the current build. `Ctrl+Shift+M` is reserved for "Import SQL" in the shortcut registry but has no handler attached yet. This page only documents what's actually reachable from the UI.
</Note>

## Export Data

1. Run a query or open a table (this produces a result in the grid)
2. Click **Export** on the results toolbar
3. Choose a format (CSV, JSON, or SQL) and configure options
4. Click **Export**, choose a save location

Only the in-memory result currently shown is exported.

<Tip>
Use `LIMIT` in your query to control export size for large tables.
</Tip>

### Export Formats

<Tabs>
  <Tab title="CSV">
    | Option | Default |
    |--------|---------|
    | Delimiter | `,` |
    | Include header row | Yes |

    NULL values are written as empty strings.
  </Tab>
  <Tab title="JSON">
    | Option | Default |
    |--------|---------|
    | Pretty print | No |
    | Array of arrays (instead of array of objects) | No |
  </Tab>
  <Tab title="SQL">
    | Option | Default |
    |--------|---------|
    | Table name (used in generated `INSERT` statements) | `export` |
    | Batch size (rows per `INSERT`) | 100 |
    | Include `CREATE TABLE` | No |

    Generates `INSERT INTO "table" (...) VALUES (...);` statements; string values are quoted and single quotes are escaped by doubling.
  </Tab>
</Tabs>

A live preview of the first 5 rows in the chosen format is shown in the export dialog. There's also a **Copy** action to copy the preview text without saving a file.

## Clipboard Paste (CSV/TSV)

Paste tabular data directly into the data grid. Press `Ctrl+V` after selecting a row. Format is auto-detected: tabs parse as TSV, commas as CSV.
