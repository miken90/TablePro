# TablePro

A personal, non-profit, Windows-only database client. Built on Tauri v2 (Rust + React/TypeScript).

## Why TablePro?

<CardGroup cols={2}>
  <Card title="Native Windows App" icon="bolt">
    Tauri desktop shell — small footprint, no browser chrome.
  </Card>
  <Card title="6 Databases" icon="database">
    PostgreSQL, MySQL/MariaDB, SQL Server, SQLite, MongoDB, Redis — compiled-in Rust drivers, no plugin downloads.
  </Card>
  <Card title="Smart Autocomplete" icon="wand-magic-sparkles">
    Context-aware autocomplete with schema and syntax awareness.
  </Card>
  <Card title="Secure Connections" icon="lock">
    SSH tunnels with password and key authentication. DPAPI-encrypted saved passwords.
  </Card>
  <Card title="AI SQL Assistant" icon="sparkles">
    Inline suggestions, chat, and context-menu actions. Claude, OpenAI, Ollama, and more.
  </Card>
</CardGroup>

## Key Features

**SQL Editor**: Syntax highlighting, autocomplete, Vim mode.
**Data Grid**: Spreadsheet-like interface with inline editing, sorting, filtering, multi-row selection.
**Table Structure**: Inspect and modify columns, indexes, foreign keys.
**Import & Export**: CSV, JSON, SQL, and XLSX.
**Query History**: Full-text search across query history.
**AI Assistant**: Explain, optimize, or write SQL with Claude, OpenAI, Ollama, and other OpenAI-compatible endpoints.

- **Storage**: MSI/NSIS installer under ~15 MB
