# Installation

## System Requirements

- **Windows 10 or 11** (x64)
- **Storage**: under ~15 MB for the installer

TablePro is a native Tauri app — the WebView2 runtime it depends on ships with Windows 10/11 by default.

## Download

Get the latest installer:

- `TablePro_<version>_x64_en-US.msi` — MSI installer
- `TablePro_<version>_x64-setup.exe` — NSIS installer

Either format installs the same app; pick whichever your environment prefers.

## Installation Steps

1. Run the downloaded `.msi` or `-setup.exe` file
2. Follow the installer prompts
3. Launch **TablePro** from the Start menu

## File Associations

The installer registers `.sqlite`, `.sqlite3`, and `.db` files to open in TablePro, and a `.tablepro` connection-export file association.

## Updating TablePro

<Note>
TablePro has no in-app auto-updater. Download and run the latest installer to update; your connections and settings persist.
</Note>

## Uninstallation

Uninstall via **Settings > Apps** (Windows), or run the installer again and choose Uninstall.

To also delete all data (connections, settings, and history):

```powershell
Remove-Item -Recurse -Force "$env:APPDATA\TablePro"
```

## Troubleshooting

**Installer won't run**: Windows SmartScreen may warn about an unrecognized publisher for unsigned/community builds — click **More info > Run anyway**.

**Connection issues**: Confirm the database server is running and not blocked by a firewall.

See [Development Setup](/development/setup) for building from source.
