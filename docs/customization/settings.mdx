## General Settings

### Language

| Option | Description |
|--------|-------------|
| **English** | English (default) |
| **Tiếng Việt** | Vietnamese |

<Note>
Changing the language requires restarting TablePro.
</Note>

### Page Size

Rows loaded per page for query/table results. Choices: 25, 50, 100, 500, 1,000. Default is 100.

### NULL Display

Free-text field for how NULL values render in the data grid. Default is `NULL`.

### Date Format

| Format | Example |
|--------|---------|
| ISO 8601 | 2026-03-13 |
| US | 03/13/2026 |
| EU | 13/03/2026 |
| Unix timestamp | -- |

Default is ISO 8601.

<Note>
TablePro has no auto-update mechanism and does not send usage telemetry.
</Note>

## Connection Settings

### Default Timeout

| Setting | Default | Range | Description |
|---------|---------|-------|-------------|
| **Default timeout** | 30 seconds | 0 -- 3600 | Query timeout preference. `0` means unlimited. |

### Safe Mode

Controls confirmation prompts before destructive or write operations:

| Level | Behavior |
|-------|----------|
| 0 -- Off | No checks |
| 1 -- Silent | Log to console only |
| 2 -- Alert (default) | Confirm DELETE/DROP/TRUNCATE |
| 3 -- Alert+ | Confirm all DML + DDL |
| 4 -- Safe | Confirm and type the table name to proceed |
| 5 -- Read-Only | Block all writes |

See [Safe Mode](/features/safe-mode) for details.

### Remember Passwords in Windows Credential Manager

Off by default. When enabled, saved connection passwords are additionally mirrored into the Windows Credential Manager (DPAPI encryption is always applied regardless of this setting).

## Performance Settings

| Setting | Default | Range | Description |
|---------|---------|-------|-------------|
| **Streaming threshold** | 10,000 rows | 1,000 -- 1,000,000 | Row count above which query results stream instead of loading all at once |
| **Store max rows** | 100,000 rows | 10,000 -- 10,000,000 | Maximum rows kept in memory for a query result |

## Diagnostics Settings

Lists local crash dumps: Rust panic JSON dumps from `%LOCALAPPDATA%\TablePro\crashes\` and Windows Error Reporting native dumps from `%LOCALAPPDATA%\CrashDumps\`. Refresh the list or delete individual entries; attach them manually when filing a bug report.

## Keyboard Settings

Customize keyboard shortcuts for commands. See [Keyboard Shortcuts](/features/keyboard-shortcuts#customizing-shortcuts) for full details.

### Rebinding Shortcuts

1. Open **Settings** > **Shortcuts**
2. Click the shortcut next to any action
3. Press the new key combination
4. Save (or Save Anyway if it conflicts with another shortcut)

### Conflict Detection

Assigning a shortcut already in use shows an inline warning naming the conflicting command. **Save Anyway** applies the new binding regardless: if the conflicting command already has a customized binding, that binding is swapped back onto the current command's previous shortcut; if the conflicting command is still on its default, both commands end up bound to the same key.

### Reset

Each shortcut has its own **Reset to default** control. **Reset All** appears when any shortcut has been customized and restores every shortcut to its default binding.

## Settings Storage

Settings are stored in:

```
%APPDATA%\TablePro\settings.json
```

### Resetting Settings

To reset everything to defaults, delete the file above and restart TablePro. Saved connections (`connections.json`, `groups.json`) live alongside it and are unaffected.

<Warning>
Resetting preferences does not affect saved connections or query history.
</Warning>
