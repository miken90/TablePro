# Editor Settings

Configure the SQL editor in **Settings** > **Editor**.

## Font Settings

### Font Family

Available monospace fonts:

| Font | Description |
|------|-------------|
| **Consolas** | Classic Windows monospace (default) |
| **JetBrains Mono** | -- |
| **Fira Code** | Ligature-friendly monospace |
| **Monaco** | Traditional Mac programming font (also installable on Windows) |
| **monospace** | Generic OS monospace fallback |

The editor's font CSS stack is `<selected font>, Consolas, 'Courier New', monospace`, so if a selected font isn't installed, TablePro falls back to Consolas, then Courier New, then the browser's generic `monospace`.

### Font Size

| Setting | Range | Default |
|---------|-------|---------|
| Font Size | 10-24 pt | 14 pt |

## Display Settings

### Word Wrap

Off by default. When on, a long line soft-wraps at the width of the editor instead of scrolling horizontally; the line is not altered, only how it is drawn. Toggling applies to the open editor immediately, keeping your text and cursor position.

### Vim Mode

| Option | Description |
|--------|-------------|
| **Off** | Standard editing keybindings (default) |
| **On** | Modal Vim keybindings -- see [Keyboard Shortcuts](/features/keyboard-shortcuts#vim-mode) |

## Indentation Settings

### Tab Width

2, 4, or 8 spaces (default 4). This sets both how wide an existing tab character is drawn and how much whitespace an indent inserts, so `Tab` and auto-indent-on-typing both step by the width you pick. The editor indents with spaces, not tab characters. Changing it applies to the open editor immediately.

## Editor Behavior

### Autocomplete

Autocomplete is always on. See [Autocomplete](/features/autocomplete) for details.

Font, font size, Vim mode, word wrap, and tab width all apply immediately with no restart required.

| Run all queries | `Ctrl+Shift+Enter` |
| Format SQL | `Ctrl+Shift+F` |
| Explain query | `Ctrl+Shift+X` |
| Toggle comment | `Ctrl+/` |
| Select next occurrence | `Ctrl+D` |
| Find | `Ctrl+F` |
| Undo | `Ctrl+Z` |
| Select All | `Ctrl+A` |
