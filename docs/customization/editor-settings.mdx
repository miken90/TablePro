# Editor Settings

Configure the SQL editor in **Settings** > **Editor**.

## Font Settings

### Font Family

Available monospace fonts:

| Font | Description |
|------|-------------|
| **Consolas** | Classic Windows monospace |
| **JetBrains Mono** | Default |
| **Fira Code** | Ligature-friendly monospace |
| **Monaco** | Traditional Mac programming font (also installable on Windows) |
| **monospace** | Generic OS monospace fallback |

If a selected font isn't installed, TablePro falls back to the browser's generic `monospace`.

### Font Size

| Setting | Range | Default |
|---------|-------|---------|
| Font Size | 10-24 pt | 14 pt |

## Display Settings

### Word Wrap

| Option | Description |
|--------|-------------|
| **Off** | Long lines scroll horizontally (default) |
| **On** | Long lines wrap to next line |

### Vim Mode

| Option | Description |
|--------|-------------|
| **Off** | Standard editing keybindings (default) |
| **On** | Modal Vim keybindings -- see [Keyboard Shortcuts](/features/keyboard-shortcuts#vim-mode) |

## Indentation Settings

### Tab Width

| Setting | Options | Default |
|---------|---------|---------|
| Tab Width | 2, 4, or 8 spaces | 4 |

## Editor Behavior

### Autocomplete

Autocomplete is always on. See [Autocomplete](/features/autocomplete) for details.

All editor settings apply immediately. No restart required.

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Run query | `Ctrl+Enter` |
| Run all queries | `Ctrl+Shift+Enter` |
| Format SQL | `Ctrl+Shift+F` |
| Explain query | `Ctrl+Shift+X` |
| Toggle comment | `Ctrl+/` |
| Select next occurrence | `Ctrl+D` |
| Find | `Ctrl+F` |
| Undo | `Ctrl+Z` |
| Select All | `Ctrl+A` |
