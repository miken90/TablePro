# Appearance Settings

Configure how TablePro looks in **Settings** > **Appearance**.

## Theme Mode

Three options: **Light**, **Dark**, **System** (follows the OS setting). There is no custom theme editor, theme import/export, or theme registry.

## Connection Colors

Color-code connections for quick identification:

| Color | Suggested Use |
|-------|---------------|
| None | Default, neutral |
| Red | Production databases |
| Orange | Staging environments |
| Amber | Testing databases |
| Yellow | Testing databases |
| Green | Development/local |
| Emerald | Development/local |
| Blue | Shared databases |
| Indigo | Shared databases |
| Purple | Special purpose |
| Pink | Personal projects |

Ten fixed color presets plus **None** -- there is no custom color picker or hex input.

### Setting Connection Color

1. Open the connection form (edit or create)
2. Find the **Color** field
3. Select a color from the palette
4. Save the connection

### Connection Color Display

Connection colors show up in editor tab headers and the connection indicator in the toolbar. They do not currently appear in the sidebar connection list.

<Tip>
Use red for production databases as a visual reminder to be careful with queries.
</Tip>
