# Quick Start Guide

Download, install, and run your first query.

## Step 1: Download and Install TablePro

Get the latest `.msi` or `-setup.exe` installer and run it. See [Installation](/installation) for details.

## Step 2: Create Your First Connection

Click **New Connection** and fill in your database details. Common examples:

**PostgreSQL**: Host `localhost`, port `5432`, username/password
**MySQL / MariaDB**: Host `localhost`, port `3306`, username/password
**SQLite**: Browse to `.sqlite` or `.db` file (no auth required)
**SQL Server**: Host `localhost`, port `1433`, username/password
**MongoDB**: Host `localhost`, port `27017`, optional username/password
**Redis**: Host `localhost`, port `6379`, optional password

## Step 3: Test and Connect

1. Click **Test Connection** to verify your settings
2. A green checkmark confirms the connection works
3. Click **Create** to save and connect

## Step 4: Explore Your Database

The main interface has three panels:

- **Sidebar**: Your databases and tables
- **SQL Editor**: Write and execute SQL queries
- **Data Grid**: View and edit query results

### Try Your First Query

1. Click on a table in the sidebar to view its contents
2. Or type a query in the SQL editor:

```sql
SELECT * FROM users LIMIT 10;
```

3. Press `Ctrl+Enter` to execute the query
4. View the results in the data grid below
